# Vibe Coding Portfolio

Личный лендинг-портфолио в стиле Cyberpunk/Neon.
Разработано с использованием **React**, **TypeScript**, **Tailwind CSS** и **Vite**.

## 🚀 Как настроить под себя

### 1. Аватар и Скриншот приложения
1.  **Аватар**: Добавьте ваше фото в папку `public` и назовите его **`photo.jpg`**.
2.  **Скриншот приложения**: Добавьте скриншот вашего главного приложения в папку `public` и назовите его **`nutrilens-screen.jpg`**.
    *   Рекомендуемый формат: Вертикальный, соотношение сторон примерно 9:19 (как на телефоне).

### 2. Ссылки и Тексты
Основные данные находятся в компонентах:
*   `components/Hero.tsx` — Заголовок и описание.
*   `components/MainProject.tsx` — Главный проект (NutriLens) и список остальных.
*   `components/Footer.tsx` — Ссылка на Telegram.

## 🛠 Установка и запуск

```bash
npm install
npm run dev
```

## 📊 Аналитика
Подключена Яндекс.Метрика (код находится в `index.html`).

*   Tailwind CSS (с кастомными анимациями neon/glow)
